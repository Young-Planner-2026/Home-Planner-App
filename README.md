# 재무플래너

AFPK 영 플래너 챌린지 2026 선택 제출물. 재무설계 사례 보고서 「29세 중소기업 재직자의 부채 상환과 부천시 소사구 신혼전세 준비를 위한 재무설계」(가상 고객 B안)의 계산과 6단계 절차를 그대로 따라가 볼 수 있는 웹앱입니다.

- 서버·로그인·외부 AI가 없습니다. 모든 숫자와 문장은 브라우저 안의 계산 결과입니다.
- `index.html`을 더블클릭해도 열립니다. 휴대폰에서는 홈 화면에 설치할 수 있습니다.
- 화면의 고객은 가상 인물이며 실제 금융정보가 아닙니다. 금융상품은 추천이 아니라 비교 예시입니다.

## 3분 만에 보는 방법

1. 첫 화면에서 **[설계 예시 불러오기]** → 5단계 입력을 넘겨 보고 **[자가진단 완료하고 시작하기]**
2. 「상담 진행 상태」에서 자가진단 → 진단 → 설계안 → 고객 선택 → 실행·점검 흐름 확인
3. **고객 화면**: 목표 진행 고리, 이번 달 할 일, 주거자금 그래프, "이사 날, 돈을 다 내고 나면?" 카드
4. **설계사 화면**: 왼쪽 메뉴가 재무설계 6단계 순서입니다. `4 설계안 → 설계 근거`, `5 실행 → 지급일 자금표`, `6 점검 → 계산 검증`을 권합니다.

## 화면 구성

**고객 화면(모바일 우선)** — 홈 · 이번 달 기록 · 내 계획 · 알림 · 더보기
- 목표 진행 고리와 중간 목표(대출 완제 → 비상금 → 적금 만기 → 보증금 반환 → 이사)
- 계획 대비 실제 기록, 거래내역 CSV 불러오기, 예정 결제
- 주거자금 그래프(적금 납입분·돌려받을 보증금 포함), 설계 전·후 비교, 제안·수정안 선택

**설계사 화면(PC 우선)** — 재무설계 6단계
1. 상담: 고객 개요, 상담 범위(관계 정립), 위험성향
2. 정보: 고객 정보·목표, 목표·배우자·주거목표·확인 질문, 변경 이력
3. 진단: 목표 판정, 진단 지표, 유동성
4. 설계안: 설계 근거(상환 대안·생활비 조정·적금 비교·대출·정책 적합성), 계획 버전·제안, 설계 도구(역산·충격 시나리오·소득 가정·상품 비교)
5. 실행: 지급일 자금표, 실행 일정, 실행 기록·예측
6. 점검: 점검 주기·기준, 경보·수정안, 경보 기준, 계산 검증, 상담 리포트(A4 인쇄)

## 계산을 믿을 수 있는 근거

- 계산 엔진은 화면과 분리된 순수 함수(`src/engine.js`)이고 월별로 결정론적으로 계산합니다. 확률 표현은 쓰지 않습니다.
- 자동 테스트 162개(`node --test tests/*.test.js`). 그중 정답 테스트 22개는 보고서 표의 숫자를 그대로 기대값으로 둡니다. 같은 결과를 앱 안 `6 점검 → 계산 검증`에서도 볼 수 있고 월별 계산표를 CSV로 내려받을 수 있습니다.
- AI가 틀렸던 부분과 사람이 고친 부분은 `records/verification-log.md`, 요청과 결과는 `records/prompt-log.md`에 남겼습니다.

## 폴더

```
index.html, style.css, sw.js, manifest.webmanifest, icons/
src/        계산(engine, judge, metrics, solver, scenarios, alerts …)과 화면(src/ui)
data/       가상 고객·정책·상품 조사 자료(출처와 확인일 포함)
tests/      자동 테스트와 정답 사례
records/    작업 기록
docs/       GitHub Pages(브랜치 /docs 방식)용 사본 — scripts/sync-docs.js로 생성
```

## 올리는 방법(GitHub Pages)

이 폴더 전체를 저장소에 올리면 `.github/workflows/pages.yml`이 테스트를 돌린 뒤 배포합니다.
저장소 Settings → Pages → Source를 **GitHub Actions**로 두세요. (Actions를 쓰지 않으려면 Source를 "Deploy from a branch", 폴더를 `/docs`로 해도 됩니다.)
